00总纲：一套反直觉的写作观

这三集不是三个并列的技巧清单，而是一条有先后的因果链。你先有一个具体的情节，才知道开头要确认什么基调；基调定了，才知道取材往哪个方向；取材决定细节，细节决定描写能不能堵住读者的退路；描写的分寸又取决于语言质感；质感之后才是对话、角色、叙述者与结构。跳过任何一环，后面的技巧都会空转。

速读 · 3 条
  • 小说不为说明道理而存在，价值在被阅读的每个瞬间——这是全部技巧的落脚点。
  • 不问「好不好」，只问「具体不具体」：大纲让人瘫痪，有画面的事件让人动笔。
  • 所有技巧服务同一件事：读者此刻的感受。写每一段都可以拿这句话自查。
写作的依赖顺序：从最底下的一层开始 核心结构

A

这份手册的组织方式

三集视频原先的顺序是：第一集讲观念与质感，第二集讲开头与对话，第三集补成语、补对话的对象感，再讲角色与叙述者。但按这个顺序读，你会在第二集才发现「开头服务基调」，而基调这个概念在第一集末尾才出现。所以手册按**依赖关系**重排：先讲「写什么」，再讲「怎么让人愿意读」，最后讲「谁在讲」。每一处论断后面都标了出处，形如 P1 01:11，点开可以直接跳回原片核对。

需要先说明一个边界：这三集是**创作观念课**，不是写作练习册。讲者反复强调「这是最简单的规律」「经过练习你会发现很多例外」，所以手册保留了这个态度——它给的是判断依据，不是配方。

01动笔之前：不要大纲，要一个具体的情节

几乎所有入门教程都从「人物小传 + 故事大纲」开始。这套流程的问题不在于它错，而在于它把最难的判断推到了动笔之前——而人在没动笔的时候，是判断不出这个故事值不值得写的。

速读 · 3 条
  • 大纲给人「已经想清楚了」的错觉，实际写起来依旧无处落笔。
  • 起点应该是一个具体到有画面的情节：一个事件，或一段对白。
  • 好开头的真正作用是断掉回头路——写完它，你只能往前写。

1.1 为什么「先写大纲」会把人卡住

讲者的判断很直接：

P1 00:09网上的教程一般是教你写人物小传或者大纲之类的东西,我觉得这很糟糕。

理由不是大纲没有用，而是它的性价比被高估了：

P1 00:14先不提这种做法对小说质量的影响,仅仅是有了人物和大纲,想要动笔依旧困难。
注意这个让步结构：先搁置「对质量有没有帮助」，只谈「能不能让你动笔」。

这是一个很实用的检验标准。大纲写完，你手里有的是一份关于小说的说明书；而写作需要的是一个**已经发生在你脑子里的场面**。说明书不会自己长出句子。

1.2 什么叫「具体的情节」

讲者给的定义只有两句：

P1 00:30我说的情节可以是一个很有画面感的事件
P1 00:33或者一段精彩的对白
两个例子都取自现成作品，而且都是可以被「看见」的：

例 · 《百年孤独》里的一场死亡

何塞·阿尔卡蒂奥死后，他的血绕开地毯，贴着墙一路流回母亲家里。

P1 00:38使他的血绕开地毯
P1 00:40贴着墙一路流回他自己的家

这不是「一个人死了」这个信息，而是一条血的行进路线。它自带方向、材质和终点，甚至自带一个母亲的视角。你不需要大纲也能开始写，因为你已经看见了。

例 · 《哈姆雷特》里那段独白

讲者称它为

P1 00:42哈姆雷特里那段已经过度模因化的独白
。「模因化」这个词很准：那段独白已经被引用到失去痛感，但它原本是一个人在极端处境里的自我盘问。选它当起点，等于选了一个已知强度的引擎。

两个例子共同的要求是：

P1 00:46要求是它必须是具体的东西
P1 00:49是与大纲完全相反的东西
这句话是整章的核心。

1.3 好开头是给自己上的一把锁

很多人以为开头是写给读者看的，讲者把它翻了过来——开头首先是写给自己看的：

P1 00:19一个好的开头就是在提醒自己没有办法再回去反复删改了,无论如何必须顺着开头写下去了。

这个功能比「吸引读者」更早生效。反复改开头是新手最常见的拖延方式，因为它永远可以更好；而一个已经定稿的开头会把后面所有句子都变成「必须与它相容」的选择题，写作于是从无限可能变成有限推演。

1.4 整本书只服务那一个情节

接下来是全书最反直觉的一段：小说不是用来表达思想的载体。

P1 01:08小说从来不是为了说明什么道理
P1 01:11小说的意义就在于被阅读的每个瞬间
P1 01:14是情节本身给予了小说价值

把这三句连起来看，写作的因果就颠倒了：不是「我有一个想法，所以我要写小说」，而是「我有一个场面，我要让读者完整地经历它」。前者写完会留下一个教训，后者写完会留下一次经历。所以讲者说，为这个情节你需要做三件事——

  1. 写下三个你能「看见」的场面，每个不超过两句话，不写解释。
  2. 从三个里挑一个，问自己：读者要预先知道哪三件事，这个场面才成立？
  3. 给这个场面写一个开头，写完就锁住，不许回头改。

02开头：先定基调，再留悬念

开头要干两件事，而且是两个不同层面的事：告诉读者「这是什么类型的故事」，以及让读者「想知道接下来会怎样」。前者是语境，后者是悬念。语境界定读法，悬念提供动力。

速读 · 3 条
  • 不要用对白开场：词语的含义由语境决定，而对白是最缺语境的一种句子。
  • 开头的第一功能是确认基调（叙述的语境），第二功能才是留下悬念。
  • 不要假想一个读者去猜他喜欢什么——你自己感兴趣的东西，读者才会感兴趣。

2.1 为什么不要用一句响亮的台词开场

P2 00:05在绝大多数情况下,小说的开头都不应该是对话。用一句响亮的台词开始故事听上去当然很帅气,

反对的理由不是「俗」，而是语言学上的：

P2 00:11但是词语的含义总是被语境决定的。
讲者用了三个层次来拆这句话，从课堂到私下再到舞台：

例 · 「太阳从东边升起」的三次使用

在初中地理课上，这句话在传授知识；在私下场合说，它可能是在讽刺你；

P2 00:26同样的一句话,一个字不差,在现实中说出来,或在脱口秀的舞台上说出来,观众理解的方式就完全不同了。

同一串字符，三种读法。对白的问题就在这里：它把一句话摆到读者面前，却还没建立让读者选对读法的语境。

2.2 开头真正要交代的是「读法」

P2 00:34小说开头最重要的作用是确认小说的基调,也可以说是叙述的语境
这句话后面跟了一串自问：现实主义？魔幻现实主义？幻想小说？严肃作品？

讲者举的例子很锋利：当主角说「真是见了鬼了」，他是在用修辞，还是这个世界真的会见到鬼？这个问题不解决，后面所有描写都会被读错——恐怖会被读成幽默，反讽会被读成抒情。所以基调不是气氛装饰，它是读者用来判断「这句话该不该当真」的开关。

顺带一提，讲者把「口吻」和「视角」列为基调里最重要的两件事，但要留到后面讲（见第 8 章）。这个安排本身说明：基调是结果，口吻与视角是手段。

2.3 悬念：读者不往下看，后面写什么都没意义

P2 01:00小说如果不能吸引读者看下去
P2 01:02那么后面写什么都没有意义了

这句话容易被读成功利主义，但它其实是在讲信息顺序：你精心准备的一切都在后半段，而读者随时可以合上书。悬念不是花招，是让后半段有机会被读到的最低条件。

2.4 不要假想一个读者

这里有一个很常见的方法论陷阱：作者设想「读者会喜欢什么」，然后照着写。讲者的反驳是：

P2 01:07只要能让作者感兴趣的东西

紧接着一句很短的话：P2 01:09「读者就会感兴趣」。

P2 01:11不要假想出来一个读者

理由在下一句：

P2 01:14但这种东西不是能凭空编造出来的
一个被凭空设计出来的「读者偏好」既不可靠，也无法验证；而作者自己真实的兴趣是可观察、可追查的。这条建议的实操含义是：取材要从自己身上取，而不是从市场上取（下一章就是具体做法）。

动手做 · 3 项
  1. 把你想写的开头第一句读出来，问：这句话如果脱离上下文，有几种可能的读法？
  2. 用一段景物或一个动作替换它，让读法只剩一种。
  3. 在开头 300 字内埋一个具体的疑问（不是形容词式的「神秘」），确认读者会想知道答案。

03取材：临场感的原料，来自你不看手机的那四十分钟

「想不到具体的情节」是最普遍的卡点。讲者给的不是灵感方法，而是一套观察配额：把每天本来就在路上的时间，改成不输入信息的时间。

速读 · 3 条
  • 取材不是等灵感，是给自己安排不被信息占满的时间。
  • 细节的两个功能：让人相信这个故事，让人感觉自己在场。
  • 临场感是有剂量的一生效果：站得够近，才可能被溅到。

3.1 一个不爱出门的人怎么取材

P2 01:24首先说明的是我是一个很讨厌出门的人

讲者先把自己的生活方式说得很极端——不逛商场、不进实体店、两年没去过餐厅——然后给出唯一稳定的取材窗口：上班路上四十分钟。关键不在路，而在这句话：

P2 01:37这个期间内我不会看手机

不看手机、不听音乐，把这段时间的注意力空出来。于是他说自己能随口说出发生在公交车上的

P2 01:46十件值得写进小说里的事情
。这里的方法论是：不是去「找素材」，而是停止用信息填满感知。

例 · 十几颗核桃

P2 01:49比如之前我见过夜晚的公交车
P2 01:51地上有十几颗核桃

后面接的是：核桃随着车的运动从一侧滚到另一侧，发出咔咔的声响。讲者说这个画面适合放进那种已经被写烂的「连接阴阳两界的末班车」故事里，作为鬼怪出现之前的铺垫。

注意这个例子的结构：一个可复现的物理运动 + 一个声音 + 一个它刚好能嵌进去的旧套路。取材的产物不是「灵感」，是一块可以直接砌进墙里的砖。

3.2 细节买的是两样东西

P2 02:03取材另一个重要作用
P2 02:04是帮助作者丰富细节

这两样东西分别是可信与在场。可信是底线：读者不信这个故事，写得再动人也没有用。在场是增益：站得太近，就会

P2 02:22会被故事中的侠客比武
——这句玩笑话把临场感的机制说清楚了：距离决定冲击。读者站得够近，才可能被溅到。

把这两条放在一起看，会发现细节不是「描写得更多」，而是「让事件的物理性成立」。核桃会滚、会响，所以那辆夜车是真的；血会绕开地毯，所以那场死亡是真的。

动手做 · 3 项
  1. 明天通勤时把手机收起来，只记三样东西：一个声音、一个动作、一个不该出现在那里的物体。
  2. 给这三样东西各找一个能嵌进去的旧故事类型（鬼故事、悬疑、爱情）。
  3. 用其中一样，写 200 字，不准出现形容词式评价（如「阴森」「诡异」）。

04描写：不是装饰，是控制注意力的方向盘

很多人把描写理解成「不影响情节的段落」，于是要么写得过多，要么干脆不写。讲者否定了这个分类本身：小说里没有「非叙事的句子」，每一句都在做事。

速读 · 3 条
  • 「直接叙事 / 间接叙事」是个假问题，小说是综合体验，每个句子都直达目的地。
  • 描写的作用是操控注意力：让读者看这里，或看那里。
  • 描写最终是为了堵住读者的退路，让痛苦或狂喜穿过文字抵达他。

4.1 被否定的那个分类

网上常见的一种区分是：有的句子在讲故事（直接），有的句子只是描写（间接）。

P1 01:23在网上似乎有不少人都这样区分
P1 01:25这种区分方式相当错误
错误源于一个更深的假设：
P1 01:28以为小说是讲述故事的工具
。

讲者的反例极短：

P1 01:33当然我们看恐怖小说
P1 01:35是不是为了看人类如何战胜邪祟
P1 01:37而只是为了被吓一跳
如果小说是「讲述故事的工具」，恐怖小说的目标就该是「讲完这个战胜邪祟的故事」；但读者的真实目的是被吓到。目标是体验，不是信息。

P1 01:40小说是一种综合的体验
P1 01:43每一个句子都直达它的目的地

这两句取消了「主线 / 闲笔」的等级制。一个句子的合法性不来自它是否推进情节，而来自它是否在做你想要它做的事——包括让读者停顿、屏息、或者分神。

4.2 注意力是可以被分配的

P1 01:45描写是操控读者注意力的手段

既然是手段，就有对象和方向：有时让人盯住事件的发展（P1 00:49），有时让人沉进氛围与情绪（P1 00:50）。写一段描写之前先决定这一句要读者看哪儿，比决定「写多少字」有用得多。

4.3 堵住退路：描写最狠的用途

这是全篇最有力的一段论证。先给结论：

P1 01:56描写的一个重要意义是堵住读者的退路

然后是机制。当故事变哀伤，读者会本能地逃离——

P1 02:01要求自己把注意力移到别的地方去
，或者在心里告诉自己「这只是小说，是作者编的」。这是一条心理退路，读者随时可以走。充足的描写做两件事：一边把注意力拉回他正想逃开的那个情节，一边模糊他的认知，让他恍惚以为自己真的亲眼见过那个世界。退路被堵住，情绪才有机会穿过来。

描写如何把情绪送进读者 核心结构

A

注意这句话的分寸：描写不是让人「感动」，是让人「无处可逃」。前者靠煽情，后者靠密度。

动手做 · 3 项
  1. 找一段你自己写的悲伤场景，标出读者可能逃离的三个位置（换视角、插入解释、突然幽默）。
  2. 在每个位置补一个具体的物理细节（温度、声音、手上的触感），把出口堵上。
  3. 删掉所有直接命名情绪的词，只留动作与物件。

05语言质感：三个减法

这一章没有「要怎么写」，只有「不要怎么写」。三个减法的共同逻辑是：凡是能替读者省力、但也会替读者省掉感受的表达，都要减掉。

速读 · 3 条
  • 同一个词连续出现要减：同一物件换属性称呼，同一人换关系称呼。
  • 「但是/因为/所以/不过」要减：这些词效率太高，会把句子变成信息提取。
  • 成语要减：「苦不堪言」出现一万遍，读者也不会得到任何新感受。

5.1 减重复：给同一个东西换名字

第一个是尽量减少同一个词连续出现的次数（P1 02:28–P1 02:30）。

做法是按属性给同一个物件换称呼。以桥为例：

P1 02:35交替地使用石头桥
，再往下是「拱桥」「小桥」，或者干脆用比喻，说成P1 02:39「倒扣的弯月」。写人同理，按关系与视角换称呼：
P1 02:45比如张三可以是小张三哥张先生
，再往下是「他」「男人」「拿着石头的家伙」，或者起个外号。

这里要区分两种重复：一种是无意识的词穷（同一段里三次「桥」），一种是有意的复沓（用来制造节奏）。讲者说的是前者。判断方法很简单：如果替换之后句子没有任何变化，那就是词穷。

5.2 减连接词：but 前面的话不必听

P1 03:11第二个方法删掉虽然但是因为所以不过这个词

理由不是这些词难看，而是它们**效率太高**——高到替读者完成了理解，读者于是不再感受句子本身。讲者引了一个流行的说法，并老实交代自己记得不一定准：

大意是：一句话里如果有一个 but，那 but 前面的话就没有必要再听了（P1 03:22）。而小说里出现的「但是」，效果是一样的（P1 03:25）。

效果是让读者变成信息提取器：他会在心里把句子切成「重点」和「铺垫」，只取后半句。而写作想要的是每句话都被感受。同一条逻辑还适用于句式：不要写「张三拿起一块石头。张三把石头扔出去。」（P1 02:56），直接写「张三拿起一块石头扔出去」（P1 03:01）。

5.3 减概括：别把一整段人生压成一句判断

这一条是从连接词那条延伸出来的，但更隐蔽。讲者举的例句是「茉莉恨自己的母亲，搞砸了派对」（P1 03:41、P1 03:42）。这句话的问题不是不真实，而是太省事：它把一个复杂关系压缩成一个因果判断，读者接收到了信息，却没经历任何东西。

讲者的改法是：把它展开成母女的一段晨间对话，或者变成「茉莉瞪了母亲一眼」，让关系变得暧昧而不是确定（P1 03:42）。

后面那句补充很关键：茉莉恨母亲的原因可能是多种多样的，写作时不要扼杀现实的丰富性，

P1 03:48把人写成单线程的AI。

5.4 减成语：第三个减法，也是最后补上的一个

成语是在第三集开头补讲的，讲者自陈这是第一集漏掉的第三项：

P3 00:00第一期讲文字质感的时候忘了讲还有第三个应该从新手时期就减少使用的东西,成语。
P3 00:08成语的表达效率实在太高了,小说不是写报告

报告的目标是让读者尽快了解发生了什么；小说的目标是让读者沉浸在话语里。这两个目标对「效率」的评价完全相反。所以：

P3 00:16苦不堪言,这四个字就算出现一万遍,也不让读者从中得到任何新的感受。
真正要回答的是「什么苦、为什么苦、怎么苦、为什么没法言说」，而这四个问题恰恰是四个字替你取消掉的。

替代方案是把它拆成一个可感的画面。讲者给的正例是一句长长的比喻——他觉得自己像秋天里一片脆得能发出声响的落叶，被握在一只看不见的手里（P3 00:40）。对照之下，「苦不堪言」是结论，「脆得能发出声响的落叶」是证据。读者信证据。

三个减法：对象、做法、理由 补充

B

动手做 · 3 项
  1. 在你最近写的一千字里，数一下「但是/因为/所以/不过」的出现次数，删掉一半，读一遍。
  2. 找一个你用过三次以上的名词，给它准备三个不同角度的称呼。
  3. 把一处成语改写成动作或画面，字数不限，但不许用评价性形容词。

06对话：临场感最强，所以最该节制

对话是最像「现场」的写法，也正因如此，它会吃掉它后面所有句子的临场感。这一章讲三件事：对话该放在哪儿、怎么写才像人说的话、以及人为什么要说话。

速读 · 3 条
  • 对话几乎是最强的临场感写法，所以写完它，后面写什么都显得远——通常放在一段的最后。
  • 写好对话三个技术点：省略、口语化、目的（言外之意）。
  • 人说话是为了掩饰，而掩饰需要见证者：所以对话一定有对象，对象就是语境。

6.1 对话会吃掉后面的句子

P2 02:30什么对话都要谨慎
前一句是「其实在任何时候」。
P2 02:32临场感最强的一种书写方式

机制在这里：写完对话之后，无论再写什么，都会觉得「临场感」被比下去了（P2 02:35–P2 02:37）。

这不是文笔问题，是感知的对比效应：对话把人拉到现场，紧接着的叙述就自动变成「远处的解说」。所以位置很重要——放在段落末尾，它的强度不会伤到后面的句子；如果非要在中间用，可以改成转述：把引号里的原话变成「他说他等一下会回去」，临场感被削弱，但可以自由地出现在段落任何位置。

讲者也提醒，这只是最简略的规律：练久了会发现例外，找到更复杂的规律。

6.2 三个技术点

P2 03:03另外写对话的时候新人常犯的错误就是写的太书面语
让对话像人话的三个开关 核心结构

A

第一点「省略」有一个容易被忽略的推论：如果你写的是架空世界，简称系统本身也是世界观的一部分。那个世界里的人会怎么偷懒，比他们会用什么词更能说明他们怎么生活。

第三点「目的」是三者里最难的。讲者的例子是吹嘘：

P2 03:56吹嘘他自己的成就时
P2 03:58这个人经历了某种刺激
P2 03:59对自己感到不自信
所以那句炫耀的台词，真正的意思和字面相反。同理，一个霸道总裁式的角色向旁人炫耀资产时，写出来更像一个渴求认可的孩子，而不是一个强者（P2 04:08）。

6.3 对话一定有对象，对象就是语境

第三集补了一层更根本的设定：

P3 00:50人之所以说话就是为了掩饰
P3 00:52但这个掩饰需要一个见证者
掩饰要成功，得有人认可它。

P3 00:59所以人是不会自言自语的

这条推论很硬：现实中的自言自语，多半是把它当借口，真正目的还是让附近的人听见；祈祷与精神病人的独白看似没有对象，其实对象分别是神和他幻想出来的人。

为什么这件事重要？因为语言要有确定的语境才有含义，而对话的对象是语境的重要组成部分。搞不清对象是谁，就搞不懂台词想表达什么。讲者顺势解释了一个日常现象：网上争吵之所以频繁，是因为对话的语境在不断改变，于是每个人都「说了自己没说过的话」（P3 01:30）。

例 · 《We Are the Champions》的两套语境

这首歌本来是对当时英国报纸「皇后乐队是挣钱方面的冠军」的回怼；

P3 01:47但到现在却往往被当成是积极的竞技精神

同一段旋律，对象换了，意思就翻了。写对话时可以拿这个当检查表：这句话是说给谁听的？如果换一个听者，它还成立吗？

动手做 · 3 项
  1. 挑一段你写的对话，把每句的「说给谁听」标在旁边，标不出的删掉。
  2. 给每个说话人设计一个省略习惯（他怎么简称东西），并让它在三处对话里保持一致。
  3. 把一段直白的台词改成「说的是 A、意思是 B」，不改字数。

07角色：不写设定，写事件里的裂缝

第三集正式进入角色，第一个动作是否定「人物设定 + 人物小传」这套通行做法。理由和第一章否定大纲是同构的：先于事件的东西，都是空的。

速读 · 3 条
  • 没有先于事件的角色：角色是被他正在经历的事件定义的。
  • 形容词是贫瘠的：正义与正义会冲突，知识与知识之间有裂缝。
  • 让角色迷人的不是解释，是细节制造的暧昧：无言的凝视、对话中的沉默、片刻的恍惚。

7.1 人物小传错在哪

P3 01:52网上似乎很流行教别人写人物设定和人物小传

讲者的类比很生活化：我们也不是先拥有了「智慧」「机敏」这样的品格，然后才去面对事件。品格是事件的产物，不是前提。所以：

P3 02:10没有先于事件的角色,角色是被他正在经历的事件定义的

紧接着是对形容词的清算。

P3 02:18正义和正义之间也存在矛盾
P3 02:20知识和知识之间也存在着无法弥合的裂缝
用一个词概括角色，等于假设这个词内部没有冲突；而好角色恰恰活在冲突里。

例 · 《守望者》：两种正义

法老王通过杀死数百万人停止了冷战（P3 02:25）；而夜枭的正义是用暴力制服犯罪者（P3 02:29）。

两者都叫正义，但放在一起就互相否定。如果用「富有正义感」去概括其中任何一个，这个角色立刻变得空洞——因为那个词恰好抹掉了它最有趣的部分：它和另一种正义的冲突。

P3 02:33在真实面前任何形容词都是贫瘠的
P3 02:37这一点不仅仅适用于角色塑造

7.2 把镜头对准裂缝

既然形容词不可靠，就只能写细节。而细节的作用不是「揭示」，是「制造暧昧」：

讲者举的细节都很小——

P3 02:58细节诸如无言的凝视
、对话中的沉默、片刻的恍惚，以及伴随的动作。然后是最重要的一句限定：
P3 03:03这些细节并不能直接揭示人物的真实想法

角色魅力的来源：从形容词到裂缝 补充

B

讲者把这种瞬间称为角色最有魅力的时刻：行为与想法的边界暧昧不清，读者于是产生一种洞悉角色的幻觉。注意「幻觉」这个词——他不是说读者真的懂了，而是说读者**以为自己懂了**。写作要制造的正是这个错觉，而不是一份人物档案。

动手做 · 3 项
  1. 删掉人物设定表里的所有形容词，只留三个动作。
  2. 给主角写一个「什么都不说」的场景：一次凝视、一次停顿、一个没做完的动作。
  3. 检查这个场景有没有解释任何东西；如果有，删掉解释。

08叙述者与口吻：那个你忘了安排的角色

每篇小说都有两个角色容易被漏掉：讲故事的人，和讲故事的方式。前者决定你能看见什么，后者决定读者愿不愿意听下去。

速读 · 3 条
  • 小说总有一个隐形的角色——叙述者；第一人称与第三人称都存在。
  • 视角不是选择，是省略的必然产物：小说装不下整个世界，省略就产生了视角。
  • 口吻是讲述的习惯，好坏习惯都可能有魅力；练法是听并模仿不同的人讲话。

8.1 叙述者也是角色

P3 03:16小说总是有一个隐形的角色
P3 03:18那个故事的叙述者

这一点常被误解成「只有第一人称才有叙述者」。讲者的纠正很直接：第三人称里这个叙述者同样存在，所以作者应该把他当一个角色来安排。

既然他是角色，他就有自己的口吻和视角（P3 03:25–P3 03:26）。

8.2 视角是省略的副产品

这一段论证值得慢慢读。前提是：小说不是无限的，作者没法把完整的真实世界塞进书里，必须省略相当一部分；反过来说，一本包含一切的小说也会极其无聊。于是：

P3 03:44所以小说一定会省略,因为省略也一定会诞生一个视角
同段前文还说：一个包含一切的小说也实在太无聊了。

结论是：视角不是一个可以随意挑选的机位，而是「你决定省略什么」之后自动剩下的那个位置。所以真正该问的不是「用第几人称」，而是「我打算不写什么」。

例 · 《卡拉马佐夫兄弟》的一个怪章节名

第五卷里有一章，标题就叫「这一章的关键作用暂时还很模糊」（P3 03:59）。讲者用它说明：叙述者可以公然对读者说话、可以卖关子、可以承认自己还没想好这一章要干什么。

这不是炫技，而是把叙述者当角色用——他有态度，有节奏感，甚至会跟读者讨价还价。如果你从没意识到叙述者的存在，就不可能用出这种手段。

8.3 第一人称不等于主角

P3 04:12重要的是第一人称小说叙述者

讲者的补充是：他也不直接等同于主角本人，有时是未来的主角，有时是过去的主角（P3 04:14）。这个时间差决定了叙述者知道多少、愿意说多少——一个「多年后回想」的叙述者，和一个「正在经历」的叙述者，能讲的故事完全不同。

8.4 口吻：讲述的习惯

讲者先给了一个反例。他读了几篇朋友写的第一人称小说，发现：

P3 04:24我发现他们全部是用散文一样的口吻在讲故事

问题不在于散文腔本身，而在于它和人物不匹配：一个现代故事里的主角，一开口就是「天明了便打算去朋友家里歇脚」，读者会立刻怀疑这个人是谁。口吻是最外显的层，也最容易被读者注意到，所以它很大程度上决定读者是否愿意读下去。

P3 04:48口吻可以被看作是讲述的习惯

习惯包含好的和坏的，而两者都可能有魅力——这句话很宽容，也很实用：你不需要把口吻修成一个「标准好文笔」，你需要的是让它稳定、可辨认。构成习惯的材料列得很细：字词的选择、是否有条理、是否专注比喻和形容、断句方式。

练法只有一句，但信息量很大：

P3 05:03就是听并且模仿不同的人讲话
不只是模仿语气，还要模仿他们讲述的思路——先说什么、后说什么、在哪里绕开。

动手做 · 3 项
  1. 给你的叙述者写三行小传：他是谁、他站在什么时间点讲、他不愿意讲什么。
  2. 把你小说开头的一段改成另一个人的口吻（换职业、换年龄），比较哪一版更像「这个人会说的话」。
  3. 录一段身边人讲话，只记他的断句和连接词，然后用这套习惯重写你的一段叙述。

09结构：把聊八卦的手感搬进小说

结构常被当成一组术语：倒叙、插叙、先抑后扬。讲者把它还原成一件更朴素的事——你在跟朋友讲八卦时，早就在用这些结构了。

速读 · 3 条
  • 结构不是名词清单，它回答的是「为什么要这么排」。
  • 所有结构的动机只有一个：跟读者互动，把他的注意力调到你要的位置。
  • 写作与聊八卦唯一的区别是看不到对方的脸，只能靠经验猜读者的反应。

9.1 名词之后要问「为什么」

P1 04:01说到结构可能大家立刻想到倒叙、插叙或者先抑后扬这些词。
P1 04:08重点是为什么要使用这些结构,简单来说是为了跟读者互动。

理由给得很具体：先抑后扬是为了让后面「扬」的时候张力更大更过瘾（P1 04:12）；倒叙是为了留下悬念，吸引读者看下去（P1 04:16）。换句话说，每种结构都对应一种读者状态，用之前先想清楚你要他处于什么状态。

9.2 你其实早就会用

P1 04:20事实上我们大部分人都可以熟练的操控叙述的结构
P1 04:24那就是当我们聊八卦的时候

聊八卦时的操作是：发现对方没兴趣就制造悬疑，为了效果再增加反转。写作的差别只有一处——

P1 04:32唯一的区别是不能直接看到对方的脸
。看不到脸，就只能靠经验猜读者的情绪，在适当的时候用结构做调整。

9.3 每写完一段，问自己一句话

P1 04:39比如每次写完一段就思考一下

P1 04:41「如果自己是读者，现在想知道什么？」

如果答不上来，说明这一段没有留下任何牵引，可以补一个倒叙、埋几个伏笔让读者惦记着；如果担心某一段情绪不够强烈，就提前写一些「抑」的部分，或者做夸张化处理。这套自查的价值在于：它把「结构」从一个写作前的规划动作，变成写作中的逐段微调。

P1 04:52总之结构只是作者与读者对话的一种手段

这句话和第 5 章的删连接词、第 4 章的堵退路是同一件事的三个面：作者始终在跟一个看不见的人对话，结构、描写、用词都是这场对话里的语气。

动手做 · 3 项
  1. 给正在写的一章标出「读者此刻想知道什么」，每 800 字标一次。
  2. 找出一个连续三段都没有新疑问的位置，在那里插入一个倒叙或一个未解释的细节。
  3. 把一段平铺直叙改成「先给结论再回溯」，比较两版的张力。

10收束：写作是为了搞懂自己

讲者在第一集结尾承认，整篇稿子充斥着反直觉的观点，几乎把语文课本上的知识点颠倒了一遍。最后一个颠倒，也是最根本的一个。

速读 · 3 条
  • 不是先有想法再写小说，而是通过写小说才搞懂自己在想什么。
  • 如果卡在「不知道想表达什么」，那不是准备不足，而是顺序弄反了。
  • 三集的分工：第一集给观念，第二集给开头与对话，第三集给角色与叙述者。
P1 05:24作家不是通过写小说表达自己的想法
P1 05:31作家终于搞懂了自己在想什么

这句话解决了一个很实际的困境：很多人不开始写，是因为「还没想清楚要表达什么」。按这个观点，那个「清楚」永远不会在动笔之前到来——它是写作的产物，不是前提。这也解释了为什么第一章要坚持从一个具体情节目开始：具体的场面可以写，抽象的立意不能写。

A.1 为什么需要校订

语音识别的置信度均值看起来很好，却不代表内容正确。三集的识别里，「法外狂徒」被识别成「法爱狂徒」，「第一人称」被识别成「低人称」，「都要遵守」被识别成「不要遵守」——最后这个错误直接把意思说反了。这类错误模型错得很自信，靠置信度阈值抓不到。

所以校订按证据强弱排序：画面字幕最硬（讲者自己打的字），其次是上下文语义与外部资料（人名、书名、作品设定），最后才是识别置信度。凡是字幕与语音冲突且无法确认的地方，手册不引用，正文只用可核实的内容。
